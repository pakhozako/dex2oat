# 自定义工作台档位说明

Dex2oat Lock 的自定义工作台分为安全、谨慎、危险三档。档位只控制 WebUI 展示和可配置范围，不会自动强制启用所有选项；真正生效的是用户保存后生成到 `system.prop` 的配置。

## 安全

- 适合人群：日常用户、首次安装用户、稳定性优先用户。
- 配置范围：低风险 dexopt、后台维护、预读、厂商私有触发项。
- 主要影响：减少后台 dex2oat、dexopt、缓存预读和厂商私有编译触发，降低发热、耗电和后台 I/O。
- 风险水平：低。通常不改变全局编译强度，不主动追求全量 AOT。
- 建议用法：默认长期使用；安装后先观察首页和诊断状态，再决定是否进入更高档位。

## 谨慎

- 适合人群：理解 ART / dex2oat / dexopt 基本含义，愿意逐项验证的进阶用户。
- 配置范围：全局 dex2oat filter、编译线程、CPU 绑定、JIT/profile、runtime/device_config、ROM 私有高级项。
- 主要影响：可能改变安装耗时、后台维护负载、编译并发、发热、耗电和部分 ROM 调度行为。
- 风险水平：中。大多数选项不是必然危险，但跨 ROM 差异明显，需要逐项启用并重启验证。
- 建议用法：一次只改少量选项；保存后检查 apply、health、conflict、integrity 摘要。

## 危险

- 适合人群：测试用户、愿意承担兼容性和稳定性风险的用户。
- 配置范围：全量 AOT、ART Service/JIT、堆参数、ISA、GC、runtime 深层开关和高风险厂商项。
- 主要影响：可能让安装明显变慢、发热升高、空间占用增加，也可能引发应用兼容异常、系统维护任务异常或 ROM 私有服务冲突。
- 风险水平：高。进入危险模式和保存高风险配置需要风险确认。
- 建议用法：仅用于测试或明确目标调优；出现异常时优先恢复默认配置、重新抓取匹配并重启验证。

## WebUI 提示

- 三档按钮提供悬停 tooltip，说明该档位的核心影响。
- 自定义工作台顶部会显示当前档位的“适合 / 影响 / 注意”说明卡。
- 每个规则项卡片会显示作用说明、目标属性和可选值；点击卡片主体可展开更多文字，点击开关只切换启用状态。

## 维护注意

- 风险档位只影响 WebUI 呈现、配置范围和用户确认，不应改变底层状态模型。
- 新增规则项必须同步更新 `webroot-src/data/options.json`、生成后的规则数据和相关说明。
- 修改危险档位时必须确认 WebUI 风险确认、保存事务、`system.prop` 输出和状态摘要仍保持一致。
