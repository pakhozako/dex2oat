# Dex2oat Lock

![:name](https://count.getloli.com/@dex2oat?name=dex2oat&theme=moebooru&padding=7&offset=0&align=top&scale=1&pixelated=1&darkmode=auto)

## 📌 项目简介

Dex2oat Lock 是一个面向 Android Root 环境的 ART / dexopt 属性调控模块。模块在安装时读取设备现有属性，通过内置规则包生成 `system.prop`，并在开机后应用和复查相关运行时属性。

v6.0 以 v5.9 为基线进行轻量升级，保留原有安装与运行结构，不引入额外协议、持久化确认目录或复杂安装事务层。

## 🎯 设计目标

Android 版本、厂商 ROM 和 Root 实现对 ART / dexopt 属性的支持并不完全一致。直接套用固定配置可能写入无效属性，也可能与其他模块产生重复或冲突。

Dex2oat Lock 采用规则驱动方式：先采集当前设备可见属性，再根据规则决定是否保留、替换或使用默认值。最终配置来自设备状态和规则定义，而不是一份对所有设备完全相同的模板。

## 🔧 主要功能

### 规则驱动生成配置

安装时会解码内置规则包，采集 ART / dexopt 相关属性，并生成最终 `system.prop`、匹配记录和配置来源摘要。对于 `defaultEnabled=true` 且设备未提供采集值的规则，v6.0 会使用规则定义的默认值，避免默认规则只计数却未真正写入配置。

### 运行时属性应用

开机服务等待系统启动完成后应用匹配属性。写入时优先使用 `resetprop -n`，不可用或失败时回退到 `setprop`，随后读取属性值确认实际结果。

### Property Lock

模块根据当前 `system.prop` 生成属性锁定列表，并在运行阶段复查受管理属性。该机制用于减少属性被其他启动脚本覆盖后长期偏离目标值的情况。

### 状态与日志

运行状态保存在 `/data/adb/dex2oat-lock`，包括安装、匹配、属性应用、服务、健康检查、完整性检查和冲突检测结果。安装日志、服务日志与 Action 日志均在本地保存，并带有基础轮转控制。

### 健康与完整性检查

健康检查确认关键文件、生成配置和运行状态是否可用。完整性检查按内置 SHA256 基线核对核心文件，帮助识别缺失或被修改的模块内容。

### 模块冲突检测

模块会扫描其他模块的 `system.prop`，报告与当前受管理属性重复的配置。带有 `disable` 或 `remove` 标记的模块会被跳过，避免对已禁用或待移除模块产生误报。

### Action 操作

模块管理器的 Action 入口支持查看状态、重新匹配规则、立即应用属性和刷新诊断：

```sh
sh action.sh status
sh action.sh rematch
sh action.sh apply
sh action.sh diagnose
sh action.sh all
```

不带参数执行时会进入基于音量键的操作菜单。

## 🧩 适用场景

- 需要统一管理 ART / dexopt 相关系统属性。
- 希望配置依据当前设备环境生成，而不是直接复制固定模板。
- 需要检查其他模块是否写入了相同属性。
- 需要通过状态文件和本地日志排查规则匹配或属性应用结果。

## 📦 安装与兼容性

请通过 Magisk、KernelSU 或 APatch 的模块管理器安装 ZIP。模块使用标准模块结构和统一安装流程，不提供单独的平台专用安装器。

模块保留 `skip_mount`，不挂载或替换 `/system` 文件。KernelSU 与 APatch 不支持 Recovery 安装，请在 Android 系统已启动后通过模块管理器安装。

不同 Android 版本和厂商 ROM 可能忽略、覆盖或重新解释部分属性。规则命中表示模块已生成配置，不代表 ROM 一定采用该属性。

## 📝 v6.0 变化

- 基于 v5.9 代码重新构建，保持原有生命周期和状态结构。
- 修复默认启用规则在无采集值时未写入 `system.prop` 的问题。
- 增加安装前规则包、关键文件和状态目录可用性检查。
- 配置生成完成并验证后再替换现有配置，失败时保留上一份有效配置。
- 冲突检测跳过带 `disable` 或 `remove` 标记的模块。
- 移除安装入口中对旧状态目录和模块目录的预清理。
- 运行时跳过值未变化的属性，减少重复写入和日志量。
- 收紧启动等待、锁和重试边界，异常时记录状态并退出。
- 精简 Action 状态展示，增加规则、配置、健康和冲突摘要。
- 更新版本号与完整性基线。

发布地址：[v6.0](https://github.com/pakhozako/dex2oat/releases/tag/6.0)

## ⚠️ 注意事项

本模块需要 Root 权限，并会修改 ART / dexopt 相关运行时属性。修改这些属性可能影响应用安装、后台编译、功耗和系统稳定性。安装前请备份重要数据，并确保知道如何通过模块管理器禁用或卸载模块。

若安装后出现异常，先禁用模块并重启，再结合 `/data/adb/dex2oat-lock` 下的状态和日志确认具体原因。
